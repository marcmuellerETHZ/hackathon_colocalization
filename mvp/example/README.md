# Example input for run_coloc_mm.R

Two loci from the project's simulated **validation** split (valid_grid_v1, M4 subsample). They were generated by the project simulator (src/sim) from 1000 Genomes 30x haplotypes on validation-split LD blocks. Both are in cell L2|P3|rho=0.8:
- L2 = the LD comes from a real external reference of n_ref = 150, not from the study;
- P3 = full sample overlap, true ρ = 0.8.

The files were written by `make_example.py`, which needs the original project data.

| Name | locus_id | Oracle class | p | n1 = n2 | n_ref | rho_hat |
|---|---|---|---|---|---|---|
| L2_S_locus | valid_grid_v1__L2_P3_rho=0.8__S__0009230 | S (shared causal variant) | 1000 | 1000 | 150 | 0.3959701144286405 |
| L2_W_fallback_locus | valid_grid_v1__L2_P3_rho=0.8__W__0009204 | W (too weak to call) | 949 | 300 | 150 | 0.7566814583467568 |

Files per locus:
- `<name>.sumstats.tsv.gz`: snp, beta1, se1, n1, maf1, beta2, se2, n2, maf2 (OLS statistics, 17 significant digits);
- `<name>.ld_factor.txt.gz`: n_ref x p standardised reference genotypes, with a header of SNP ids (R = XᵀX / n_ref);
- `<name>.meta.json`: locus metadata.

Expected output (`expected_output.json`; it equals the benchmark's stored coloc_susie_mm predictions exactly):

| Name | P_S | P_D | s | Path | Call (t_S 0.840, t_D 0.732) |
|---|---|---|---|---|---|
| L2_S_locus | 0.9227656937864273 | 0.005965138056285942 | 0.9227656937864986 | SuSiE (1 CS per trait) + coloc.bf_bf | S |
| L2_W_fallback_locus | 0.003135550087379315 | 0.0056957805352454765 | 0.3550484316991166 | coloc.abf fallback (no CS) | insufficient |

```
Rscript mvp/run_coloc_mm.R --sumstats mvp/example/L2_S_locus.sumstats.tsv.gz \
  --ld-factor mvp/example/L2_S_locus.ld_factor.txt.gz --n-ref 150 --rho-hat 0.3959701144286405
```
