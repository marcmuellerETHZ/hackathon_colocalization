## Model (z scale)
z = [z1; z2] ~ N((I₂⊗R̃)b, V⊗R̃), R̃ = (1−η)R + ηI, V = [[1, ρ̂],[ρ̂, 1]]; b = Σ_l β_l ⊗ e_{j_l}, j_l uniform,
s_l ∈ {0, 1-only, 2-only, both} with prior π, β_l | s ~ N(0, U_s): U₁ = diag(σ²_l1, 0), U₂ = diag(0, σ²_l2),
U_both = [[σ²_l1, c],[c, σ²_l2]], c = ρ_u σ_l1 σ_l2. With diag R = 1 the SER at variable j is bhat_j = r_j ~ N(β, V) (no R⁻¹).

## Decisions / assumptions
1. **R̃ in both mean and covariance** (same convention as Family B, DESIGN §5 B), so the SER needs no R⁻¹; η is estimated after each IBSS sweep by maximising the ELBO over η ∈ [1e-8, 0.95] (log scale, Brent, keep-old rule) given q(b).
2. **η spectrum (M3.5, batched)**: genotype-factor LD with n_ref ≤ p uses the eigen-decomposition of the n_ref × n_ref Gram matrix X̃X̃ᵀ in float64 (exact; the p − rank null-space directions carry eigenvalue η); dense LD (and factor LD with n_ref > p) uses batched `torch.linalg.eigh` in float64 (default). Option `eig_dtype=float32` (≈3× faster for dense p = 2,000): eigenvalues ≤ 1e-6·λ_max are treated as null space and **η is floored at 1e-3** (`eta_min_fp32`; the float32 spectrum cannot resolve smaller η; B uses the same floor). The η Brent runs in one fused Triton kernel (`eta_kernel.py`), equal to the torch path (test).
3. **EB of prior scales**: per effect, per trait (σ²_l1 then σ²_l2, coordinate-wise), each by R's Brent on log σ² ∈ [−30, 15] with susieR's keep-old rule and null check (σ²_t ← 0 if it does not increase the SER likelihood). Initial σ² = 50 (z scale). `prior="fixed"` uses given U matrices. The Triton EB kernel precomputes the σ²_t-independent part of the SER likelihood once per Brent run (2 exp per variable and evaluation instead of 5 exp + 1 log; identical up to fp64 rounding). `eb_fast_exp` (float32 exp inside, off by default) was measured at only 1.3–1.45× faster and is not used.
4. **State prior π (M3.5)**: `pi_mode="eb"` (default) — per-locus MAP/EM after each sweep, π_s ∝ Σ_{used l} q_l(s) + κ π_ref,s with κ = `pi_prior_strength` = 4 and π_ref = `pi` = (¼, ¼, ¼, ¼); "used" effects are those with a non-zero prior scale (effects with both scales 0 have q_l(s) = π and zero KL for every π, so they follow π at no cost; the update is then the exact one-step fixed point). The ELBO used for convergence includes the Dirichlet(1 + κπ_ref) log-prior. `pi_mode="fixed"` keeps π = `pi` (M3 behaviour; used by the mvsusieR identity). κ and π_ref are to be tuned on validation (D6(g)); EB costs ≈ 1.5–2× more IBSS iterations (median 7 vs 4 at p = 2,000). Known limitation: when a trait has no signal, EB sets σ²_l2 = 0 and the 'both' and '1-only' states become identical, so their split follows π (EB cannot separate them).
5. **ρ_u = 0** by default (simulator draws effect signs independently).
6. **z adjustment**: z·√((n−1)/(z²+n−2)) per trait with n = median per-SNP N (as susie_rss / mvsusie_rss); z then standardised by √diag(R). Diagonal of R̃ taken as 1 after standardisation.
7. **Convergence**: ELBO, tol 1e-3, rule `susie014` (Δ < tol) by default; `susie016` (iter > 1 and 0 ≤ Δ < tol, as mvsusieR) for the identity test; `alpha` (max |Δα| < `tol_alpha` = 1e-4, iter > 1) — required with layer E. max_iter 100.
8. **Reported posteriors are the fitted q**: per-effect state probabilities and events use the residual stored at each effect's last IBSS update (and, with layer E, the inflation used then).
9. **Power events (M3.5, DESIGN v4 §1)**. Marginal noncentrality of effect l at variable j: μ_t = β_t + m_{−l,t,j} with m_{−l} = R̃ E[b_{−l}] = z̃ − r_l (plug-in of the other effects' posterior means; their posterior variance and the in-sample-vs-reference LD difference are ignored — this is the approximation). Events: powered_t = {|β_t| ≥ τ_t} ∩ {|μ_t| ≥ τ_t} (own effect AND marginal, as §1); 'power ≥ 0.2' (blocking, used for w_l and for "not blocking" in p̃) = {|μ_t| ≥ w_t} ∩ {|β_t| ≥ w_t}. **Deviation from the oracle's μ-only "nonweak"**: without the own-effect guard, an effect of the fit with β ≈ 0 in the 'both' state at a variable in LD with strong distinct signals would count as an LD-inflated shared causal variant and block D (e.g. an unused effect with σ² ≈ 0 and state probabilities equal to π); the guard removes this. Option `nonweak_own=False` gives the μ-only version; `power_marginal=False` gives the M3 own-effect-only events. Effects with both prior scales 0 contribute no events (exact under the guard). Bivariate probabilities are evaluated only where α·P(both | j) times a 1-D upper bound of the event exceeds 1e-13 (total omitted mass ≤ L·p·1e-13).
10. **Thresholds by trait TYPE** from the locus attributes `trait1_type` / `trait2_type` ('gwas': τ = 6.29, w = 4.61; 'mol': τ = 5.26, w = 3.58; equal to `sim.params` TAU/WEAK, tested). Missing attributes → ('gwas', 'mol') with `types_from_attrs = false` in `extra`; unknown values raise.
11. **Exclusion probabilities** (layer D): E₂ = Π_l(1 − Σ_{j∈CS₁} α_lj P(l has own |β₂| ≥ w₂ at j)), where CS₁ is the union of the 95 % variable credible sets (no purity filter) of effects with P(powered in trait 1) ≥ 0.5; E₁ symmetric; NaN if CS_t is empty. Own effect, weak threshold w of the trait's type (DESIGN §5 layer D writes λ).
12. **Layer E (M3.5, ablation `ref_var=True`)**: per-variable variance inflation of the SER likelihood, r_j ~ N(β, D_j V D_j), D_j = diag(√(1+δ_1j), √(1+δ_2j)), δ_tj = Σ_{i ∈ top-32 of E[b_t²]} E[b_ti²]·κ(r²_ij, min MAF_ij)/n_ref (self-pair 0; cross terms Cov(r̂_ij, r̂_i'j) ignored), updated after each sweep from the posterior second moments. κ = n·Var(r̂) from the empirical table `ref_ld_var_v1.json` (pool resampling of NFE = pools A ∪ B, 40 train-split windows, n ∈ {100, 150, 254}, FPC-corrected; table of the calibrated n closest to n_ref on the log scale; empty cells → MAF-pooled value of the r² bin; MAF bins used only when `maf_ref` is given). The normal-theory (1 − r²)² is close for common pairs at r² < 0.5 but too small by 2.5× (r² 0.7–0.8) to ~19× (r² 0.95–0.98) for common pairs (min MAF ≥ 0.2), and ~6.7× for rare pairs (min MAF < 0.05) at r² 0.3–0.5 (`ref_ld_var_v1.md`); n·Var is stable across n for MAF ≥ 0.05, not for rare pairs. With layer E the SER updates no longer maximise the ELBO (it remains a valid bound), hence convergence by α; the EB Brent runs in torch (no Triton) — ablation speed only.
13. **Continuous batching (M3.5)**: loci are grouped by LD kind and p (p_max ≤ 1.1·p_min); each group runs with a working set of min(max_batch, 6 GB / per-locus bytes) rows; converged rows are flushed and refilled from the queue once ≥ 25 % of the rows are done. Results equal single-locus fits up to fp64 rounding (test; a near-tie in an EB null-check decision can amplify rounding to ~3e-4 in PIP on rare loci, in any batched fit).
14. **mvsusieR identity uses null_weight = 0** and `pi_mode="fixed"`: mvsusieR's variable log-BF renormalises the non-null mixture weights, so its `null_weight` does not enter α or the IBSS. A proper null state (ours) cannot be matched for π₀ > 0; with π₀ = 0 the models are identical.
15. Variable credible sets (for reporting / CS₁) reuse susieR 0.14.2 `susie_get_cs` logic with "V" = max(σ²_l1, σ²_l2).
16. Method: `rho_hat` NaN → 0; one LD for both traits; `runtime_s` = amortised batch wall time.

## P3-5 / P3-6 fixes (task p3.famA_fixes; DECISIONS P3-5, P3-6)
17. **Ablation ladder** (`method.LADDER`): `base` → `+rho` → `+eta` → `+E` → `+multistart` → `+perTraitLD` (cumulative); `ladder_config(rung)` / `ladder_method(rung, pi_mode="eb"|"fixed", nonweak_own=True)`; a rung may also be a '+'-joined component list, e.g. `rho+eta+multistart+perTraitLD` (no layer E). Every rung has η floor 1e-3, the `rel` stopping rule (layer E: `alpha`), the own-effect guard and π by EB (κ = 4); `pi_mode="fixed"` (π = ¼ each) is the P3-6 sensitivity and `nonweak_own=False` the μ-only option. `JointConfig()` defaults are the P3-5 method (multistart and per-trait LD on, η not estimated unless asked).
18. **Multi-start IBSS** (`multistart`, `noshare_sweeps` = 5): every locus is fitted from the default start and from a 'no-shared-first' start (π_both = 0, other states renormalised, for the first 5 sweeps; π EB and convergence suspended there; the ELBO trace restarts after the phase). Both starts are rows of the same batches (adjacent, same p group), so the cost is ≤ 2× the single start (2× IBSS rows, 2× η spectra). The fit with the higher final ELBO is kept (`start`, `elbo_starts` in the result / `extra`). The default start is the single-start fit, so the kept ELBO is never lower (test).
19. **η floor** (`eta_floor` = 1e-3) on all rungs: rungs without η estimation use fixed η = 1e-3; the η Brent's lower bound is max(1e-8, eta_floor). `eta_floor=0` (+ `multistart=False`) restores M3.5 behaviour and is used by the identity tests (DESIGN: identity at η = 0). The floor makes the likelihood proper (ELBO bounded) on rank-deficient factor LD, but it does not make the base rungs good fits there: on a toy with two reference-identical columns that differ in the study (Δz = 6–9), η = 0 diverges (ELBO +260–550 per sweep, σ² → e¹⁵), η = 1e-3 is bounded but still rising by 5–10 per sweep after 200 sweeps (σ² ≈ e¹³), η = 1e-2 converges in ≈ 60 sweeps, and estimated η converges (test). The bounded optimum sits at effects ≈ Δz/(2η).
20. **Stopping rule `rel`** (default): converged if ΔELBO < tol (1e-3, as susie014) or |ΔELBO| < tol_rel·|ELBO| (1e-6) or max|Δα| < tol_alpha (1e-4; iteration > 1). The ELBO scale includes the η constants only when η is estimated (otherwise the ELBO omits the η-independent constant, so the relative part is looser in absolute terms). Caveat: the α part also stops runs whose ELBO is still rising because effect sizes grow with α fixed (the rank-deficient mode of item 19).
21. **Per-trait LD at L0** (`per_trait_ld`): when a locus provides a trait-2 LD of the same kind (`R2` dense or `X_ref2` factor, attrs `ld_type2` / `n_ref2`), the mean map is blockdiag(R̃_1, R̃_2) (each standardised, diag 1; z_t standardised by √diag R_t), so the residual of trait t uses R̃_t and the SER is unchanged. The ELBO's quadratic term uses V⁻¹-weighted per-trait products, which gives the cross-trait matrix (R_1 + R_2)/2; the η terms use log|R̃_1| + log|R̃_2| and [z̃_1ᵀR̃_1⁻¹z̃_1 + z̃_2ᵀR̃_2⁻¹z̃_2 − ρ z̃_1ᵀ(R̃_1⁻¹ + R̃_2⁻¹)z̃_2]/(1 − ρ²). Exact for ρ = 0, and identical to the one-LD model when R_2 = R_1 (test, any ρ); for ρ ≠ 0 and R_1 ≠ R_2 it is a working approximation (no joint noise covariance has exactly these SER margins), so IBSS is then not guaranteed monotone. η uses the torch Brent (no Triton) in this mode. Layer E's δ and the credible-set purity use trait 1's LD. Loci without a trait-2 LD (or with a different kind) use one LD; groups are split by has-ld2 so L1+ loci carry no extra memory. **Input**: the shared reader (`eval.io`) does not load `R2`/`X_ref2`; call `famA.method.attach_ld2(set_path, loci)` before `fit_batch` (the per-locus `extra.per_trait_ld` records whether it was used). The 4-line reader/harness change that would load it for the harness is described in `reports/p3.famA_fixes.md` (not made: eval-owned files).
22. **Layer-E table v2** (`ref_ld_var_v2.json`, artifact `ref_ld_var@v2`, job `famA_refldvar_v2`; review p2 defect 3): same 40 train-split windows and draws as v1 (same seed key), but draws in which either variant of a pair is monomorphic in the subsample are excluded for that pair (v1 set r̂ := 0, which never occurs at inference). Common-pair cells are unchanged; rare pairs (min MAF < 0.05) drop at high r²: [0.8, 0.9) 1.90 → 1.03, [0.9, 0.95) 1.04 → 0.38, [≥ 0.995) 0.89 → ≈ 0; at r² 0.3–0.5, 2.49 → 2.19 (still ≈ 6× normal theory). **Lookup convention**: the table is binned by the full-pool r², but layer E looks it up by the reference r̂² (errors-in-variables mismatch; not corrected).
