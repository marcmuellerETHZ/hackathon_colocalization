- **Per-testset lock (M8):**
  - **`src/eval/testset_lock.py` (new).**
    - `lock_for(config)` returns the config's lock. A config without a `lock:` block is v1 and gets exactly the phase-1 values: results/test_access.log, any `frozen-*` tag, configs/FROZEN_SHA256 and data/processed/testset_v1.
    - A `lock:` block never inherits v1 values.
    - `lock_problems` rejects a non-v1 lock that uses the v1 log, a `frozen-` prefix, or a log that eval.io does not honour.
  - **`src/eval/io.py`.** `ACCESS_LOGS = ((results/test_access.log, "frozen-"), (results/test_access_v2.log, "frozen-v2"))`.
    - `has_test_access` grants a nonce only through the log it was started in, at a commit carrying that log's tag prefix.
    - The v1 rule is unchanged.
  - **`scripts/eval_test.py`.** A new `--testset` option (default configs/testset_v1.yaml means unchanged behaviour). The lock of that config selects:
    - the access log, read for the committed and working-tree checks and written for started/interrupted/resumed/completed;
    - the tag prefix;
    - the hash list (`check_frozen` on configs/FROZEN_P2_SHA256 for v2);
    - the default output directory.

    The v2 run never reads or writes the v1 log.
- **In-run disjointness (`eval.testrun.Pipeline.disjointness_check`).**
  - When the config has `disjoint_from`, it runs right after generation, before any method sees a locus.
  - It enumerates every generation key the generator may have used: window passes; cand and fin for every candidate index k < n_candidates per cell, from generate()'s stats files.
  - Against the reference set it checks:
    - **key-tuple overlap**;
    - **derived 64-bit seed overlap** (common.seeds.derive = sha256 of the key tuple);
    - **locus-id overlap**.
  - In the v2 test run the reference is v1's own run: `results/eval_test/test_frozen-v1_ab94c5a1/state/sim.json` gives its stats and truth ids, read inside the v2 access window.
  - In a dry run the reference is validation stats (valid_grid_v1, shifted_dry_v1). Any overlap aborts the run and writes state/disjoint_FAILED.json.
- **`src/eval/testrun.py`.** The test-mode seed is now the config's `seed` (`Pipeline.run_seed`) instead of the constant 20261028; for v1 this is the same value. It drives:
  - generation;
  - the slow subsample;
  - the C4 bootstrap;
  - the real-arm bootstrap.
