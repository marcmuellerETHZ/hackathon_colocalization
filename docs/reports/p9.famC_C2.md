## Verdict

C2 (DESIGN v4 §5 C; DESIGN_P2 §2 C, §4) on the M4 main validation subsample (m4_subsample@1 `main.txt`, 12,170 loci,
80 LD blocks). All methods were scored with least-favourable failure scoring, and every method had 0 failures.

| (i) recalibrated ECE "equal or better" than B (net − B ≤ 1 paired SE) | ECE_S 0.044 vs 0.109 (−0.066, SE 0.005); ECE_D 0.013 vs 0.114 (−0.101, SE 0.005) | ≤ +1 SE | pass |

**C2 FAILS.** Per DESIGN §5 C, C is demoted to a fast pre-filter and is not a candidate (DESIGN_P2 §4; PI decision
D28). The verdict was independently recomputed and confirmed, with the verifier's own code (neither src/eval nor
src/famC): reviews/p9_verify_C2.md.

The full-scale network is far ahead of the phase-1 families, ahead of the floor by a margin that just clears the
1-SE bar, and inside the region-gap bar. It fails only because its LD inputs add nothing measurable: the network
trained without any LD-derived input reaches the same realistic AUPRC on the same records and schedule.

Paired SE is the SD of 2,000 cluster-bootstrap replicates over LD blocks of the difference, on loci scored by both
methods (DESIGN_P2 §4 M3). Replicates are seeded rng(20261029, "famC_C2", comparator), and the recalibration
intercept is refitted within each replicate. The joint run_benchmark (BCa, block, 2,000 replicates; benchmark
`results/benchmarks/20261028T143030Z_famC_C2_m4`, job `famC_p9_c2_bench`) gives the same point estimates. Its
BCa 95% intervals are:
- net − floor: +0.0053 [−0.0040, 0.0095];
- net − nold: −0.0013 [−0.0064, 0.0027].

## Region gap (DESIGN_P2 §2 C)

- **Set.** famC_trainregion_m4@1: 11,599 loci from train-split windows with the M4 design. That is the 34
  configs/testset_v1.yaml cells, 100 S / 100 D / 100 W per cell, and G 1,020 / U 379 kept as they arose up to 30 per
  cell.
- **Generator.** It was generated by the frozen generator (`sim.cells.build_set`, GridPlan as sim.testset) with seed
  20261030 under the key prefix ("famC_trainregion",). No draw is shared with the training records.
- **Result.** Realistic AUPRC of the C2 model: 0.9688 on this set vs 0.9641 on M4 main, a gap of 0.0047. The SE,
  0.0057, combines the two independent block bootstraps.
- **Limit.** The set has only 32 anchor blocks, against 80 for M4 main, because build_set visits windows in one
  order for all cells. Its bootstrap is coarser.
- **In-sample gap (monitoring only).** train_main's monitoring on its own trained-on records vs valid_v1 is 0.0125
  at 600k, falling from 0.019 at 75k.

## Limits

- **One training seed.** The bootstrap SEs cover locus and block sampling, not training variance. The nold
  difference (−0.0013) is well inside one SE, so a second seed could move it either way. It would not plausibly
  produce the > +0.0023 needed to pass.
- **The ablation is not fully LD-free.** Its screen membership still uses the LD-aware conditional lists
  (README C-A4). "No LD" means no LD-derived network inputs.
- **The region-gap set has 32 blocks.**
- **A's M4 run is partial.** It is limited to the realistic cells and is a provisional artifact; it only enters as
  the weaker comparator.
- **All numbers are validation-split.** No test-split data were generated, loaded or read.
