## What was run

- **Locus set:** screen_v2@2, 12,000 validation loci (6 cells × 2,000).
- **Methods on all 12,000 loci:**
  - coloc.abf: W ∈ {0.1, 0.15, 0.2} × p12 ∈ {5e-6, 1e-5}, named `coloc_abf_W<W>_p12_<p12>`;
  - coloc_susie, coloc_susie_mm, sharepro, prop_coloc, coloc_prop_test, lead_snp;
  - strength_only, with a K = 5 cross-fit over all 12,000 loci (benchmark `20261027T102443Z_p4_screen_v2_control`).
- **Slow methods** (mvsusie, colocboost, colocboost_m1), 3,000 loci in all:
  - all 2,000 loci of L0|P1|r_p=0.0;
  - 200 per other cell, 50 per generation bucket, seed derive(20261027, 'screen_slow_subsample') (`src/baselines/subsample.py`, tested).
- **mvSuSiE:** the hard rule lfsr < 0.05 is primary (P3-2); the soft-rule scores are in `extra.soft`.
- **Timeouts:** the pilot-frozen provisional values (`baselines.run.PILOT_TIMEOUTS_S` = configs/test_methods_v1.yaml).
- **Splitting:** coloc_susie and coloc_susie_mm on the 5 non-A1 cells ran as id halves or quarters to fit the 120 GB RAM budget. The id files are in `results/baselines_screen_v2/ids/`.

## Failure diagnoses

**prop_coloc (P3-20): a method limitation, not a wrapper bug.** All 7 pilot failures were reproduced outside the wrapper:
- 6 have an exactly singular LD sub-matrix among the ≤ 20 SNPs prop.coloc selects (smallest eigenvalue about 1e-15). In the n_ref = 150 reference genotypes, 3–4 SNPs satisfy x_c = x_a + x_b, so `solve()` fails inside the package's `try()`.
- The 7th fails the package's own variance check, 1 − B'A⁻¹B < 0 (trait N = 100, mismatched LD).
- In the full run, the error messages are the same family: 'solve0' not found 352, "Unable to compute the standard errors" 141, NA in `if` 16, computationally singular 3.
- Known-answer test: `tests/baselines/test_prop_coloc_limits.py`. The same toy locus fails if and only if one selected SNP is the exact sum of two others.
- No fix and no retuning (P3-20); the PI accepted blocking prop_coloc claims in L2/L4.

**Package defects, kept as failures and not patched (PI-accepted):**
- **mvsusieR 0.3.0** decides `has_mixture` from effect 1 only. When effect 1 is null but later effects form credible sets, every lfsr is returned as NA. This hit 1 L0P1 locus.
- **colocPropTest 0.9.3** drops a matrix dimension when exactly one SNP pair is left after tagging. This hit 4 loci.
- Details are in `src/baselines/README.md`, items 20 and 22.
